# Employee Portal - React Native Mobile Application

Modular folder and file structure for an Employee Portal React Native (Android) application.

## Directory Structure

- `android/`: Native Android project files
- `ios/`: Native iOS project files
- `src/`
  - `assets/`: Color constants, image keys, styles
  - `components/`: Common reusable components
  - `hooks/`: Custom React hooks (auth, attendance, leave)
  - `models/`: TypeScript interfaces and data models
  - `navigations/`: Route constants and stack/tab navigators
  - `pages/`: Application screens/pages (auth, dashboard, attendance, leave, payroll, profile, announcements)
  - `services/`: API services, HTTP fetch helpers, utility functions, storage keys
